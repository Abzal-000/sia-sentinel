Заготовки на основе docs/demand-validation.md. Правила честности действуют:
не предлагать «сделаем под вас», не называть цену до прямого вопроса,
письменный ответ важнее устного. Каждое сообщение заканчивает ГЛАВНЫЙ
ВОПРОС дословно. Ответы сохраняются в evidence/demand-answers/.

## Правила отправки (самому себе)

- Отправить ВСЕ ТРИ в течение одной недели; цель — три письменных ответа,
  не три идеальных письма.
- Письменный ответ сохранить в `evidence/demand-answers/<дата>-<орг>.md`.
- «Да, если…» — это дверь: раскрыть условия и внести в дорожную карту.
- «Нет» от 3 из 3 — данные для kill-criterion, не повод для депрессии.

## Что прикладывать / показывать (готово 2026-09-14)

- **Статическая витрина портала** — `portal/` в репозитории: реестр обеих
  записей + страницы вердиктов (ru/kk/en) + бейджи. Открывается с диска
  двойным кликом (index.html), можно прикрепить ZIP-архивом каталога к
  письму. Вердикты на страницах посчитаны независимым верификатором
  (тем же кодом, что в pip-пакете), НЕ сервером SIA — об этом есть строка
  на самой странице.
- Регенерация: `python scripts/export_portal.py` (отказывается
  экспортировать запись, не прошедшую независимую верификацию).
- Для разговора №2 (банк) акцент: аттестация против модельного риска —
  docs/sia-ai-act-mapping.md, ключ «независимая валидация и эффективный
  вызов» = перевывод вердикта третьей стороной.
