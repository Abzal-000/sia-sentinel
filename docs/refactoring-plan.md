# План рефакторинга и оптимизации SIA Sentinel (v1, 2026-09-06)

Статус проекта: запись №1 выпущена и заякорена, Б2 закрыт, sia-verifier 1.3.0
живёт на PyPI, 672 теста зелёные, фальсификационная батарея ALL CAUGHT 29/29.
Оператор ищет внешнего проверяющего (п.7) — этот план заполняет окно так,
чтобы **не поднять руку на то, что делает цифры believable**.

## Железные правила (из решений рецензента, не отменены)

1. **Хирургия, не перестройка.** Каждый шаг ≤ одного логического изменения,
   за ним: полный сьют + ruff + mypy + `scripts/falsification_battery.py`
   (29/29) + отдельный коммит. Батарея — страховочная сетка рефакторинга:
   если после шага она ловит меньше — шаг откатывается, а не чинится.
2. **Вердикт-критичное не трогаем**: `sia/statistics.py`, `llm_flow.py`
   (чекер, checkpoint/3, CHECKER_ID), формула канона обязательства,
   `_expect_met`. Правило «смена семантики = структурный бамп протокола»
   дешевле любых «улучшений».
3. **Параметры записи №1 (δ, n, пара, цены) — навсегда.**
4. **Никаких линий в multitenancy/billing/webhooks** (стоп-линия) —
   кроме явно размороженных ниже.

## Фаза 3 — Масштаб и устойчивость (гейт: фактический рост, не спекуляция)

Сейчас каждый вызов `registry.get/list/count` перечитывает ВЕСЬ jsonl —
O(N) на операцию, Merkle перестраивается O(N) при каждой вставке. При
десятках записей это неважно; план включается по триггерам:

- [ ] **3.1 Триггер: реестр > 1000 записей или > 500ms на `/v1/receipts`**
      → in-memory индекс (registry_id → offset), ленивое чтение хвоста;
      JSONL остаётся источником истины (не БД!).
- [ ] **3.2 Триггер: реестр > 10 000 записей** → SQLite-бэкенд за тем же
      интерфейсом ReceiptRegistry, JSONL — экспорт для верификатора.
- [ ] **3.3 Merkle: инкрементальный frontier** вместо полной перестройки
      (RFC 6962-стандарт); золотые тесты уже заперты — безопасно.
- [ ] **3.4 Rate limiter: persistence** (сейчас in-memory, рестарт = сброс)
      и API-ключи sha256 → argon2 с двухфазным миграционным чтением
      (SECURITY_REPORT §2 residuals).
- [ ] **3.5 JWT iss/aud валидация** — тот же residual.
