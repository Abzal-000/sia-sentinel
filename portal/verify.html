Verify it yourself

This showcase is a static export. The real proof does not require trusting us:

pip install sia-verifier

sia-verifier attestation.json --chain registry.jsonl \
  --checkpoint checkpoints.jsonl --require-coverage

sia-rederive

The chain, checkpoints and flows are in the repository (receipts/, artifacts/, flows/). The verifier checks the Ed25519 signature, the hash chain, signed checkpoints and the Merkle tree — offline, one dependency (cryptography).
